# 2-Phase AC Motor Control — STM32F407

Прошивка для управления двухфазным асинхронным двигателем на базе STM32F407VET6. Реализованы: генерация двухфазного синусоидального сигнала через ШИМ (TIM1, 4 канала); замкнутый контур по углу и скорости (каскадный PID); измерение скорости вращения вала по сигналу таходатчика (ADC2 + медианный фильтр); вывод телеметрии через SWV/ITM; аварийный останов при достижении заданного угла. Проект выполнен как практическая часть НИР/ВКР и оформлен в виде пет-проекта.

## Аппаратура

| Компонент | Параметр |
|---|---|
| MCU | STM32F407VET6, ядро Cortex-M4F |
| Тактирование | HSI, SYSCLK = 16 МГц (без PLL) |
| Силовая часть | H-мост на 2 фазы, 4 ключа (управление с TIM1 CH1–CH4) |
| Обратная связь по скорости | аналоговый таходатчик → ADC2 (канал 2) |
| Обратная связь по углу | счёт импульсов таходатчика по экстремумам производной |
| Отладка | SWD + SWV (ITM) для вывода телеметрии |

## Принцип работы

Двигатель — двухфазный асинхронный, обмотки статора сдвинуты на 90° в пространстве. Для создания вращающегося магнитного поля на обе фазы подаются синусоидальные напряжения, сдвинутые по фазе на 90°:

    Фаза A: sin(ωt)
    Фаза B: sin(ωt + 90°)

Мгновенное значение синуса переводится в скважность ШИМ: `CCR = |sin(angle)| * PWM_PERIOD`, знак синуса задаёт направление тока через H-мост (пины направления). Угол `angl1` инкрементируется в прерывании TIM2 с частотой 100 кГц, приращение за тик: `angleStep = freq / 100`. Частота `freq` — управляющее воздействие от PID-регулятора, ограничена 30…100 Гц.

### Обратная связь по скорости и углу

1. ADC2 опрашивается каждые `handler_scaler_for_adc = 40` тиков TIM2 (частота выборки ≈ 2.5 кГц).
2. Считается производная сигнала таходатчика, сглаживается скользящим средним по `DERIVATIVE_WINDOW_SIZE = 20` отсчётам.
3. Знак производной определяет направление; момент смены знака — экстремум — соответствует прохождению определённого угла валом.
4. По времени между соседними экстремумами вычисляется мгновенная угловая скорость: `ω = π·1000 / (2·Δt)`, `Δt` в мс.
5. Мгновенная скорость фильтруется медианным фильтром на 25 отсчётов — устойчив к выбросам от помех таходатчика.
6. Угол вала инкрементируется на 90° на каждый зафиксированный экстремум.

### Каскадный PID

Внешний контур — по углу:

    angle_error = angle_desired - shaft_angle_deg
    pid_angle   = KP·e + KI·∫e dt + KD·de/dt      (Kp=0.05, Ki=0.001)

Выход ограничен 20…110 и служит заданием скорости для внутреннего контура:

    speed_error   = pid_angle - ω
    pid_speed     = KP2·e + KI2·∫e dt            (Kp2=0.005, Ki2=0.0001)
    freq         += pid_speed                     (ограничение 30…100 Гц)

При достижении `shaft_angle_deg ≥ angle_desired` выставляется `stop_flag`, все ключи H-моста выключаются.

## Как собрать и прошить

### Требования

- STM32CubeIDE ≥ 1.11 (или ARM GCC + Make)
- ST-LINK (V2/V3) и драйверы
- Плата STM32F407VET6 (Discovery или кастом)

### Сборка в STM32CubeIDE

1. **File → Import → General → Existing Projects into Workspace**.
2. Корень — папка с этим репозиторием (там, где лежит `.project`).
3. **Project → Build Project** (`Ctrl+B`). Артефакт — `Debug/nir_motor.elf`.
4. **Run → Debug** (`F11`) — прошивка через ST-LINK.

### Сборка из командной строки

    make -C Debug -j

### Вывод телеметрии (SWV)

В окне отладки:
- **Window → Show View → SWV → SWV ITM Data Console**
- В настройках ITM включить **ITM stimulus port 0**
- Запустить трассировку (`Start Trace`)

В консоль выводятся две колонки: `угол (град)` и `угловая скорость (рад/с)`.

## Что реализовано (маппинг на разделы ВКР)

| Раздел работы | Файл / функция |
|---|---|
| Настройка тактирования | `SystemClock_Config()` в `main.c` |
| Инициализация ШИМ (TIM1, 4 канала) | `MX_TIM1_Init()` |
| Генерация двухфазной синусоиды | `main()` — цикл `while(1)`, таблица `sinuses[360]` |
| Коммутация H-моста | `main()` — блок `if (sinValue1 >= 0) ...` |
| Базовый таймер 100 кГц | `MX_TIM2_Init()`, `HAL_TIM_PeriodElapsedCallback()` |
| Опрос таходатчика (ADC2) | `HAL_TIM_PeriodElapsedCallback()` — блок `counter2 == handler_scaler_for_adc` |
| Вычисление угловой скорости | там же, формула `ω = π·1000 / (2·Δt)` |
| Медианный фильтр скорости | `speed_buffer`, `sorted_indices`, `position_in_sorted` |
| Каскадный PID | блоки «PID для угла» и «PID для скорости» |
| Аварийный останов | флаг `stop_flag` |
| Телеметрия SWV | `SWO_Print()` |

## Известные ограничения

- Тактирование от HSI без PLL (16 МГц) — достаточно для задачи, но не оптимально по точности ШИМ.
- Направление определяется по знаку синуса без учёта токового контура — для малых скоростей возможны рывки.
- Калибровочные таблицы `speed_table`/`adc_table` сняты для конкретного экземпляра таходатчика.
